# تريو كار ووش | Trio Car Wash & Oil Center 🚗🛢️

نظام سحابي متكامل لإدارة مغاسل السيارات ومراكز تغيير الزيوت والمخزون، مصمم خصيصاً ليناسب متطلبات وطبيعة السوق المصري.

---

## ✨ المميزات الرئيسية للمشروع

### 1. إدارة المخزون الذكية (Stock Management In & Out)
- **إضافة وتوريد رصيد (Restock)**: تسجيل التوريدات الجديدة، كميات العبوات أو اللترات، سعر الشراء والتكلفة، واسم المورد.
- **خصم أو تسوية يدوية (Reduce)**: خصم عجز جرد، توالف وعبوات مسربة، أو استهلاك داخلي للمغسلة (شامبو وفوط ومعطرات).
- **خصم آلي عند أمر التشغيل (Auto-deduct)**: بمجرد اختيار زيت أو فلتر في فاتورة السيارة، يتم خصمه لحظياً من رصيد المخزن وتسجيل حركة صرف مسندة لرقم الفاتورة واسم العميل.
- **تنبيهات النواقص والحد الأدنى (Low Stock Alerts)**: إشعارات ملونة وواضحة للزيوت والفلاتر التي أوشكت على النفاذ لتفادي تعطل العمل.
- **سجل تدقيق كامل للحركات (Audit Movement History)**: سجل تاريخي لكل إضافة أو سحب بالمخزن بالتاريخ والوقت واسم المسؤول.

### 2. نقطة البيع وأمر التشغيل السريع (POS & Quick Order)
- واجهة سريعة جداً تناسب الموبايل، التابلت، أو شاشة الكاشير.
- **تسعيرة ديناميكية حسب حجم السيارة**:
  - 🚗 سيدان / هاتشباك (Sedan)
  - 🚙 دفع رباعي / SUV / كروس أوفر
  - 🚐 ميكروباص / فان / نقل
  - 🏍️ دراجات نارية
- **أشهر زيوت وفلاتر السوق المصري محملة مسبقاً**:
  - شل (Shell Helix Ultra 5W-40, HX7 10W-40)
  - موبيل (Mobil 1 5W-30, Mobil Super 20W-50)
  - توتال إينرجيز (Total Quartz 9000 5W-40)
  - كاسترول (Castrol EDGE 5W-40)
  - فلاتر هيونداي وكيا، تويوتا، نيسان، شيري وMG، وألماني Mann Filter.
- **حساب تلقائي لعداد تغيير الزيت القادم**: بمجرد كتابة العداد الحالي واختيار نوع الزيت (10,000 كم أو 5,000 كم)، يقوم التطبيق بحساب العداد وتاريخ الموعد القادم تلقائياً!

### 3. إرسال الفاتورة وتذكير الزيت عبر WhatsApp 📱
- **فاتورة واتساب رسمية شيك**: بضغطة زر واحدة تُرسل الفاتورة كاملة بتفاصيل الخدمات والزيوت ورقم اللوحة وإجمالي المبلغ للعميل.
- **مركز تذكيرات غيار الزيت الدوري**: شاشة مخصصة للعملاء الذين حان موعد غيار زيتها الدوري لإرسال رسالة تذكيرية بضغطة زر.
- **طباعة الفواتير الحرارية**: متوافق مع طابعات الإيصالات 80mm و 58mm.

### 4. الوردية اليومية وتقفيل الخزينة (Shift & Cash Drawer)
- فتح الوردية برصيد عهدة البداية (الفكة).
- تسجيل المصروفات النثرية اليومية (شاي، فطار، صابون، صيانة طارئة).
- تصنيف الإيرادات حسب طريقة الدفع:
  - 💵 كاش (Cash)
  - ⚡ إنستاباي (InstaPay)
  - 📱 فودافون كاش ومحافظ إلكترونية
  - 💳 فيزا وماكينات البنوك
- تقفيل الوردية ومطابقة النقدية مع كشف العجز أو الزيادة آلياً.

### 5. نظام الصلاحيات (Roles)
- **حساب المدير (Admin)**: اطلاع كامل على الأرباح، تقارير التكلفة، المخزون، وسجل الحركات.
- **حساب الكاشير/الفني (Cashier)**: تسجيل الأوامر والخدمات، إدارة الوردية والمخزن الميداني بدون كشف أرباح المحل وسعر التكلفة.

### 6. سحابي ومتاح من أي مكان (Cloud & Online Access)
- **وضع العمل الهجين (Hybrid Cloud & Offline-Ready)**: التطبيق يعمل فورياً بدون انتظار، مع إمكانية ربطه بـ **Google Firebase** من داخل الإعدادات لمزامنة كل البيانات سحابياً والوصول إليها من الموبايل أو أي كمبيوتر من أي مكان في العالم!

## 🌐 خيارات النشر أونلاين (Online Deployment)

### الخيار 1: النشر عبر Firebase Hosting (مجاني تماماً)
1. قم بإنشاء مشروع جديد في [Firebase Console](https://console.firebase.google.com).
2. قم بتسجيل الدخول بالأمر:
   ```bash
   npx firebase-tools login
   ```
3. اربط المشروع وانشر:
   ```bash
   npx firebase-tools init hosting
   npm run build
   npx firebase-tools deploy --only hosting
   ```

### الخيار 2: النشر عبر Vercel (مجاني بضغطة واحدة)
- اسحب المستودع على GitHub، وادخل على [vercel.com](https://vercel.com) واختر المستودع ليتم نشره في أقل من دقيقة برابط دائم ومجاني!
